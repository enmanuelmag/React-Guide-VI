Contrato de lectura

Las props son de solo lectura

✓ Usar

return (
  <h3>{title}</h3>
)

El hijo presenta el valor que recibió.

! Reasignar

title = 'Otro título'

El hijo no modifica la entrada entregada por el padre.

La asignación es deliberadamente incorrecta y no se conserva. Si otro render necesita un valor distinto, el padre entrega otro dato. No introducir snapshots de estado.

Identidad entre hermanos

La key identifica al elemento

media.id permanece estable para ese medio.

key guía a React, pero no llega dentro de MediaCardProps.

Señalar primero el objeto concreto del fixture y su id. Después seguir media.id hasta key en App. La línea comentada { ... } representa los demás objetos y no es código que se copiará. Explicar que una lista sin key estable produce un warning. La documentación oficial indica que las keys deben ser estables y que key no llega como prop normal: https://react.dev/learn/rendering-lists.
