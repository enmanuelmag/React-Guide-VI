Componente

Un componente representa una pieza

Tiene una responsabilidad reconocible, se declara como función y puede usarse dentro de otras piezas.

Pedir que nombren la responsabilidad de cada frontera. Definir componente: una pieza declarativa de interfaz. No hablar todavía de props ni de estado.

Criterio de extracción

Responsabilidad no significa fragmentar todo

✓ MediaCard

function MediaCard() {
  return <article>...</article>
}

Agrupa una pieza completa que la pantalla puede reconocer.

! SectionTitle

function SectionTitle() {
  return <h2>Mi catálogo</h2>
}

Aísla una sola etiqueta sin resolver todavía un problema visible.

Preguntar cuál componente tiene una frontera reconocible en el producto. La comparación enseña criterio, no una prohibición absoluta: extraemos cuando aparece una responsabilidad útil.
