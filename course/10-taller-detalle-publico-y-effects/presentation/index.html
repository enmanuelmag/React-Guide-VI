Identidad de caché

La query key incorpora cada dato que cambia la respuesta

Familia["media"]
añade el recurso

añade la identidad

Query key: identidad serializable que TanStack Query usa para separar entradas de caché.

Construir la key por niveles. Tipo e id permanecen juntos porque ambos cambian la respuesta del fetcher.

Preguntar qué ocurriría si la key omitiera mediaType. Dos catálogos podrían compartir el mismo id externo.

Opción enabled

No describir enabled como botón o evento. La declaración permanece montada; la identidad determina si puede ejecutarse.

Origen de detailQuery

input entra directamente en la key y en la función.

Responder la duda de forma directa: ya no existe disabledDetailInput ni una identidad inventada. enabled evita ejecutar sin identidad; el if conserva el contrato de TypeScript y documenta el caso imposible.

Respuesta remota

detailQuery.data contiene el DTO raíz devuelto por getMediaDetail()

DTO: estructura recibida desde la frontera HTTP.

Esta sesión usa detailQuery.data.catalog. entry e isLogged permanecen en el contrato para etapas posteriores.

No presentar catalog null como fallo de red. La request puede completar correctamente y declarar que no existe catálogo.

Objeto concreto antes de abstraer

El catálogo de Dune entra al adapter con nombres de transporte

Nombres de transporte: nombres exactos que llegan en el JSON de la API, como coverUrl. Todavía no son los nombres que usará la interfaz, como posterUrl.

Fixture: dato local preparado para desarrollar y comprobar un caso conocido.

Definir nombres de transporte antes de leer el fixture. Contrastar coverUrl con posterUrl y después leer los dos nulls.

Forma incompleta

Cambiar el título sin cleanup deja un valor residual

Setup: parte del Effect que inicia o actualiza la sincronización.

Este setup escribe el valor, pero todavía no define cómo deshacerlo.

La dependencia title está bien. El problema no es el array; falta una función que restaure el sistema externo.

Sincronización reversible

El cleanup restaura el título que existía antes del detalle

  1. 1Guarda el título anterior.
  2. 2Escribe el título del medio.
  3. 3Devuelve el cleanup.
  4. 4Restaura al cambiar o salir.
Leer en cuatro pasos. El componente devuelve null porque su responsabilidad es sincronizar, no renderizar una caja visual.
