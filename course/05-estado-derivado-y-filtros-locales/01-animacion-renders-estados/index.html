03 / CONSOLALOG = console.log · FLUJO = anotación didáctica

        

        
← → pasos · Espacio pausa

        

          
Explorar el flujo
Usa ← y → o pulsa un hito. Inicio y Fin saltan al primer y último paso. Espacio activa o pausa la reproducción; Escape cierra esta ayuda.

          
Azul señala ejecución, ámbar señala cambios pendientes y verde señala valores aplicados. Cada paso se puede recuperar exactamente, incluida la consola.

          
Es una simulación didáctica, no un inspector de React. La pausa alarga eventos que en la app real son síncronos. El barrido representa calcular el JSX; el commit aplica al DOM solo los cambios necesarios.

          
Una cola común simplifica el dibujo: React administra las actualizaciones de cada estado. StrictMode puede llamar otra vez al componente en desarrollo; aquí seguimos una pasada conceptual.
