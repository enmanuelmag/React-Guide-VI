# Espacio de trabajo del framework de presentaciones

Esta carpeta contiene propuestas, comparaciones, pruebas y resultados de revisión que todavía pueden cambiar.

## Reglas

- Cada iteración declara qué decisión intenta resolver.
- Un archivo permanece aquí mientras contenga decisiones pendientes.
- Cuando el usuario aprueba una decisión reutilizable, se promueve a `../approved/` y se sincronizan `rules/presentations.md`, `ROADMAP.md` y la memoria de la iteración.
- Los experimentos visuales descartados pueden conservarse aquí con su estado explícito; no se copian al framework aprobado.
- No se crean carpetas o archivos vacíos para anticipar una implementación.

La dirección visual y el runtime están aprobados en `../approved/`. Esta carpeta conserva el [plan de implementación](implementation-plan.md) y futuros experimentos que todavía requieran decisión.
